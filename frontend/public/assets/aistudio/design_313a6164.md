# Velora Design System — Minimal Neo-Brutalism

> **Design Philosophy: "Warm Minimalist Neo-Brutalism"**  
> Velora blends the raw boldness of traditional Neo-Brutalism (stark black ink strokes, zero-blur hard drop shadows, and expressive typography) with a warm, clean, and restrained aesthetic (soft parchment canvas, generous whitespace, and curved corners). The result is friendly, high-contrast, tactile, and ultra-readable.

---

## 1. Design Principles

1. **High-Contrast Ink Lines ("The 3px Rule")**: Every interactive element, container, card, and input is defined with high-contrast, solid black borders (`#000000`) ranging from `2px` to `4px`.
2. **Tactile Zero-Blur Hard Shadows**: Depth is created strictly using directional solid offset shadows (`Xpx Xpx 0px 0px`), never fuzzy gaussian blurs. Buttons physically translate into their shadows when clicked (`active:translate-x-[4px] active:translate-y-[4px]`).
3. **Warm Paper Canvas**: Rather than harsh clinical white or eye-straining neon, Velora uses a warm, comforting off-white parchment foundation (`#fffdf8` and `#f9f6f0`).
4. **Expressive vs. Geometric Typography**: Playful, handcrafted headline titles (`Caveat Brush`) contrast against structured, highly legible geometric sans-serif body text (`Plus Jakarta Sans`).
5. **Organic Curvature (Rounded Neo-Brutalism)**: Unlike severe, sharp-cornered 90s brutalism, Velora softens its heavy ink geometry with smooth, friendly pill shapes (`rounded-full`) and spacious container radii (`rounded-[2rem]` / `rounded-[2.5rem]`).

## 3. Typography

### 3.1 Font Families

```html
<!-- Google Fonts Embed -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Caveat+Brush&family=Plus+Jakarta+Sans:wght@400;500;600;700;800;900&display=swap" rel="stylesheet">
```

- **Display Font (`font-display`)**: `'Caveat Brush', cursive`
  - Purpose: Brand logo (`VELORA`), heroic landing headers, highlighted section titles, modal titles.
  - Character: Playful brush strokes, artistic hand-drawn warmth, bold and confident.
- **Body & Interface Font (`font-sans`)**: `'Plus Jakarta Sans', ui-sans-serif, system-ui, sans-serif`
  - Purpose: UI labels, navigation links, body copy, form inputs, metadata chips, status tags.
  - Weights used: `400` (Regular), `500` (Medium), `600` (Semi-bold), `700` (Bold), `800` (Extra Bold), `900` (Black).

### 3.2 Typography Scale & Rhythm

*Note: Velora sets `html { font-size: 13px; }` (or `14px` on dashboard) to maintain tight, crisp, brutalist density across standard desktop displays.*

| Style / Element | Font | Size / Leading | Weight | Tracking / Case |
| :--- | :--- | :--- | :--- | :--- |
| **Hero Display** | Caveat Brush | `5rem` – `7rem` / `0.85` | Regular | `tracking-wide`, UPPERCASE |
| **Section Title** | Caveat Brush | `3.75rem` – `4.5rem` (`text-6xl` to `7xl`) | Regular | `tracking-tight`, Sentence or Title |
| **Modal / Card Title** | Caveat Brush | `2rem` – `2.5rem` (`text-3xl` to `4xl`) | Regular | Normal |
| **Subheading / Eyebrow** | Plus Jakarta Sans | `0.875rem` (`text-sm`) | `800` (Extra Bold) | `tracking-widest`, UPPERCASE |
| **Card Header** | Plus Jakarta Sans | `1.5rem` (`text-2xl`) | `700` (Bold) | Tight |
| **Body (Regular)** | Plus Jakarta Sans | `1rem` – `1.125rem` (`text-base` / `text-lg`) | `500` (Medium) | Normal, leading relaxed |
| **Buttons & Badges** | Plus Jakarta Sans | `0.875rem` – `1.125rem` (`text-sm` / `text-lg`)| `700` – `900` | `tracking-wider` / `tracking-widest` |
| **Captions / Stats Label**| Plus Jakarta Sans| `0.65rem` – `0.75rem` (`text-xs`) | `900` (Black) | `tracking-widest`, UPPERCASE |

## 4. Borders, Radii & Shadows ("The Ink System")

### 4.1 Border Hierarchy

- **Subtle Elements / Compact Badges**: `border-[2px] border-black`
- **Standard UI / Inputs / Buttons / Section Dividers**: `border-[3px] border-black`
- **Heavy Containers / Hero Images / Primary Cards / Modals**: `border-[4px] border-black`
- **Empty State Containers**: `border-[4px] border-dashed border-black`

### 4.2 Border Radius Scale

- **Pill (`rounded-full`)**: Primary action buttons, status pills, filter chips, search bar, avatar circles.
- **Oversized Containers (`rounded-[2.5rem]` / `rounded-[3rem]`)**: Hero images, main auth cards, profile banner card.
- **Standard Cards (`rounded-[1.5rem]` / `rounded-[2rem]`)**: Feature cards, artist grid cards, bio containers.
- **Controls & Small Cards (`rounded-xl` / `rounded-2xl`)**: Form inputs, OTP digits, icon badges, dialog boxes.

### 4.3 Shadow System (Zero-Blur Hard Drops)

Hard shadows simulate cast shadows on physical paper cards.

| Shadow Token | Tailwind Arbitrary Value | Usage |
| :--- | :--- | :--- |
| **Micro Shadow** | `shadow-[2px_2px_0px_0px_rgba(0,0,0,1)]` | Small icon boxes, status pills, chips |
| **Button Shadow** | `shadow-[4px_4px_0px_0px_rgba(0,0,0,1)]` | Standard buttons, stat cards, step numbers |
| **Accent Button Shadow** | `shadow-[4px_4px_0px_0px_#ffc86b]` | Dark buttons with yellow drop shadow |
| **Card Shadow** | `shadow-[6px_6px_0px_0px_rgba(0,0,0,1)]` | Standard feature cards, search inputs |
| **Elevated Card Shadow** | `shadow-[8px_8px_0px_0px_#ffc86b]` | Artist cards, platform highlight containers |
| **Hero / Modal Shadow** | `shadow-[12px_12px_0px_0px_rgba(0,0,0,1)]` | Hero imagery, login panel |
| **Max Modal Shadow** | `shadow-[16px_16px_0px_0px_#ffc86b]` | High-priority OTP modals, checkout dialogs |

## 5. Micro-Interactions & Physical Tactility

### 5.1 The Tactile Button Press (Press-Down Effect)
Buttons simulate a physical mechanical switch. On hover or active press, the offset shadow collapses and the element shifts by the exact shadow offset:

```css
/* Tactile Button Press Example */
.brutal-btn {
  background-color: #ffc86b;
  color: #000000;
  border: 3px solid #000000;
  box-shadow: 4px 4px 0px 0px rgba(0, 0, 0, 1);
  transition: all 0.15s ease-in-out;
}

.brutal-btn:hover {
  transform: translate(-1px, -1px);
  box-shadow: 6px 6px 0px 0px rgba(0, 0, 0, 1);
}

.brutal-btn:active {
  transform: translate(4px, 4px);
  box-shadow: 0px 0px 0px 0px rgba(0, 0, 0, 1);
}
```

### 5.2 Card Hover Elevation
Cards lift upward and expand their shadow on hover:
- Idle: `shadow-[8px_8px_0px_0px_#ffc86b] transform-none`
- Hover: `hover:-translate-y-2 hover:shadow-[12px_12px_0px_0px_#ffc86b]`

### 5.3 Layered Offset Backdrops
A signature Velora composition technique for images and hero banners:
- A colored solid background div is placed underneath:
  `absolute inset-0 bg-[#ffc86b] rounded-[2.5rem] translate-x-4 translate-y-4 border-[3px] border-black`
- The foreground image sits above:
  `relative rounded-[2.5rem] border-[3px] border-black object-cover`

### 5.4 Playful Tilt & Rotations
- Text highlights with angled background swatches: `-rotate-1`, `-rotate-2`
- Interactive logos with micro-rotations: `hover:-rotate-2`
- Pendulum animation for vector accents:
```css
@keyframes swing {
  0%   { transform: translateY(-1rem) rotate(-10deg); }
  25%  { transform: translateY(-1rem) rotate(0deg); }
  50%  { transform: translateY(-1rem) rotate(10deg); }
  75%  { transform: translateY(-1rem) rotate(0deg); }
  100% { transform: translateY(-1rem) rotate(-10deg); }
}
```

## 7. Layout & Spacing Rules

- **Page Max Widths**:
  - Super-wide hero / gallery: `max-w-[90rem]` (1440px)
  - Main section containers: `max-w-7xl` (1280px)
  - Dashboard content: `max-w-[1400px]`
  - Detailed profiles / forms: `max-w-[1100px]`
  - Auth modal / card: `max-w-md` (448px)
- **Vertical Spacing Rhythm**:
  - Section padding: `py-16 px-8 lg:px-16`
  - Section dividers: `border-b-[3px] border-black`
  - Grid gaps: `gap-6` (compact) to `gap-8` / `gap-10` (wide feature grids)
